Privacy policy

charge-line · last updated 8 October 2026

charge-line is a personal, non-commercial proof of concept. It is used only with vehicles its developer owns or is authorised to control, and is not offered to the public.

What it accesses

When you sign in with your Tesla account and approve it, charge-line receives OAuth tokens with the scopes openid, offline_access, vehicle_device_data and vehicle_cmds. It uses them only to:

  • list the vehicles on your account;
  • check whether the vehicle has approved charge-line's key and which command protocol it uses;
  • wake the vehicle; and
  • send a trip you planned — destination and stops — to the vehicle's navigation.

Where data is kept

Tokens are stored only on the computer running charge-line, in a local file. They are not sent to this website or to any server run by the developer. The stops you send go to Tesla to set the vehicle's navigation. If the optional place lookup is used, stop names and coordinates are sent to the Google Places API to find each stop's place ID.

charge-line does not sell or share data, and this website uses no cookies or analytics. It is hosted on GitHub Pages; GitHub may log visits as described in the GitHub General Privacy Statement.

Removing access

Remove charge-line's key from the vehicle's Locks screen, and revoke its access in your Tesla account's security settings. Deleting the local token file removes the stored tokens.
